# KIS — Krankenhaus-Informations-System

Ein minimalistisches, performantes Krankenhaus-Informations-System in Rust.

## Features
- Minimale Hardware-Anforderungen
- Extrem performante Datenbank
- Ansprechende GUI
- Alle gängigen Medizintechnik-Schnittstellen (HL7, FHIR, DICOM, XDS)
- Voll konfigurierbar
